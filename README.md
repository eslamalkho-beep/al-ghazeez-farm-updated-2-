# مزرعة الغزيز — نظام إدارة مزرعة الأغنام والماعز

تطبيق ويب عربي (RTL) لإدارة مزرعة أغنام وماعز: القطيع، الولادات، النفوق، السجل الصحي، المصروفات، الإيرادات، المشتريات، الشراء والبيع الجماعي، الموظفون، العهد النقدية، الإشعارات، التقارير، والإعدادات.

## التقنيات

تطبيق **ثابت من جهة العميل بالكامل** — لا يوجد خادم ولا قاعدة بيانات خارجية ولا API:

- HTML / CSS / JavaScript خام (بدون أدوات بناء أو bundler أو npm)
- **IndexedDB** لتخزين كل البيانات داخل متصفح المستخدم (قاعدة باسم `AlGhazeezFarmDB`)
- خط Cairo من Google Fonts، ومكتبتا Chart.js و SheetJS من CDN

## التشغيل محليًا

لا يوجد أمر بناء. شغّل خادمًا ثابتًا بسيطًا من جذر المشروع:

```bash
npx serve .
# أو
python -m http.server
```

ثم افتح الرابط الذي يظهر في الطرفية.

> يُفضَّل التشغيل عبر خادم محلي بدل فتح `index.html` كـ `file://` مباشرة، تفاديًا لمشاكل IndexedDB وتحميل الموارد من CDN.

## حسابات الدخول

يُنشئ `js/db/seed.js` حسابين افتراضيين تلقائيًا عند أول تشغيل فقط (عندما يكون مخزن `Users` فارغًا):

- حساب بصلاحية `manager` — وصول كامل لكل الوحدات
- حساب بصلاحية `owner` — صلاحياته محكومة بحقل `permissions`

الاسم وكلمة المرور مكتوبان داخل `js/db/seed.js`.

> ⚠️ **غيّر كلمتي المرور فور أول تسجيل دخول** من قسم «إدارة المستخدمين والصلاحيات» في صفحة الإعدادات. ملفات JavaScript تُحمَّل كاملة في متصفح أي زائر، لذلك القيم الافتراضية ليست سرية على أي نسخة منشورة.

قاعدة البيانات تبدأ **نظيفة** — لا يُدرج `seed.js` أي بيانات تشغيلية تجريبية، فقط الحسابين وبنود التكويدات الافتراضية للمصروفات/الإيرادات/المشتريات.

## النشر

المشروع موقع ثابت، ويُنشر على Vercel بدون أي إعدادات بناء:

- **Framework Preset:** Other
- **Build Command:** (اتركه فارغًا)
- **Output Directory:** (اتركه فارغًا — الجذر)

## ⚠️ أين تُخزَّن البيانات؟ (مهم)

كل البيانات محفوظة في **IndexedDB داخل متصفحك أنت**، مرتبطةً بالنطاق (origin) الذي فتحت منه التطبيق. وهذا يعني:

- البيانات **لا تُرفع مع الكود** ولا تُخزَّن على GitHub أو Vercel.
- النسخة المحلية والنسخة المنشورة لهما **قاعدتا بيانات منفصلتان تمامًا**، وكذلك كل متصفح وكل جهاز.
- مسح بيانات الموقع من المتصفح **يمسح كل شيء نهائيًا**.

### نقل البيانات بين نسختين (أو أخذ نسخة احتياطية)

من صفحة **الإعدادات**:

1. **تصدير نسخة احتياطية** — ينزّل ملف JSON يحوي كل المخازن (بما فيها المستخدمون وكلمات المرور المشفّرة ومرفقات الفواتير).
2. افتح النسخة الأخرى، ثم **استيراد نسخة احتياطية** وارفع نفس الملف.

> الاستيراد **يستبدل** محتوى قاعدة البيانات بالكامل، ولا يدمجها مع الموجود.

خذ نسخة احتياطية دوريًا — لا توجد أي نسخة أخرى من بياناتك في أي مكان.

## الأمان

المصادقة في هذا التطبيق محلية ومبسّطة (تجزئة SHA-256 بدون salt، والجلسة في `localStorage`). لا يوجد خادم يفرض أي تحقق، فكل التحقق يجري في المتصفح ويمكن تجاوزه. هذا كافٍ للاستخدام الشخصي/المحلي، لكنه **غير مناسب لحماية بيانات حساسة على رابط عام**. أي شخص يملك الرابط يستطيع فتح التطبيق (بقاعدة بيانات فارغة خاصة بمتصفحه).
